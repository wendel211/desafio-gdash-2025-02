# 🌐 Frontend — React + Vite + Tailwind

Interface moderna do sistema GDASH Weather Dashboard.

---

## 🚀 Rodar localmente
```sh
npm install
npm run dev
```

---

## 🌍 Variáveis de Ambiente (arquivo `.env`)
```
VITE_API_URL=http://localhost:3000
```

---

## 🎨 Tecnologias

* React + Vite
* TailwindCSS 4
* Recharts
* Context API
* ThemeProvider (dark/light)
* Toast system
* Modais customizados
* Axios

---

## 📁 Estrutura
```
src/
 ├── api/
 ├── components/ui/
 ├── context/
 ├── pages/
 ├── routes/
 ├── styles/
 └── App.tsx
```
